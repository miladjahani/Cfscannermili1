فایل‌ها و ساختار دایرکتوری گیت‌هاب اکشن آماده است.

مراحل استقرار سریع با ترموکس (Termux):

۱. یک ریپازیتوری خالی در گیت‌هاب خود بسازید.
۲. این فایل زیپ را در ترموکس اکسترکت کنید و وارد پوشه آن شوید.
۳. دستورات زیر را به ترتیب در ترموکس اجرا کنید:

git init
git add .
git commit -m "Init CF Scanner with GitHub Actions"
git branch -M main
git remote add origin <LINK_REPOSITORY>
git push -u origin main

۴. مرورگر را باز کنید، به صفحه ریپازیتوری خود در گیت‌هاب بروید و از تب Actions، روند ساخت اتوماتیک APK را مشاهده کنید. 
پس از ۱۵ دقیقه، فایل APK در همان قسمت برای دانلود آماده خواهد بود.
